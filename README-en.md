## 📖 Introduction

**Worse of Terraria** is a mod that tweaks Terraria gameplay mechanics. Its goal — to deliver a supposedly better gameplay experience?

## ✨ Features

Most features can be configured inside **Mod Configs**. Please check them in‑game for full details.

1. Common utility mod features such as modified item max‑stack size.
2. Greatly boosted player health, mana, and defense stats.
3. A large collection of miscellaneous features waiting for you to toggle on!!!

> Almost every feature is **configurable**. Pick what suits your playstyle!

> Recommended IDEs: Rider, Visual Studio 2026, Visual Studio Code

1. Open the project within your IDE.
2. Build within your IDE (hotkey `F5` usually launches the game quickly).
